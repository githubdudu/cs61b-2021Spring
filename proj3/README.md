# Design Document
## Classes and Data Structures
### 1. Package Rooms
#### RandomRooms
This class generates non overlapping rooms in a 2D space. 
There are two types of rooms: Main and Side rooms which could be retrieved by `getAllRooms()`, `getMainRooms()`, `getSideRooms()`. `getMainRoomCenters()` and  `getSideRoomCenters()` also have been provided to get a list of centers of corresponding rooms. `Draw()` method will run when env variable `DEV_ENV` is true to help visualize the generation process. 

First, the class generates rooms/rectangles via `RandomRectangle` class with the amount of `settings.CELL_COUNT`. This class generates random rectangles in an ellipse. The center of each rectangle is randomly generated in the ellipse defined by the major axis (a) and the minor axis (b).

Then, it fans out the rooms to ensure they do not overlap.

Next, it may remove the rooms that are at the edge of canvas that can't be drawn properly.

Finally, it separates the rooms into main and side rooms based on their size. 
##### Fields
1. `private Rectangle[] rooms` - Array of generated rooms.
2. `private final List<Rectangle> mainRooms` - List of main rooms.
3. `private final List<Rectangle> sideRooms` - List of side rooms.

#### RandomRoomGenerator
This class can generate random rectangles whose center falls into an ellipse. `nextRectangle()` will create a new random rectangle. 

This centre of the rectangle will be created inside the ellipse provided. The width and height of rectangle will be generated by poisson distribution by private methods: `randomWidth()` and `randomHeight()`.

##### Fields
1. `private final Random random` - the random object.
2. `private final double lambda` - the coefficient for the poisson distribution when generating the width and height of the rectangle.
3. `private final Ellipse2D ellipse` - the ellipse in which the center of the rectangle will be generated.



### 2. Package Delaunay

#### Triangle

A euclidean triangle representation. It has a subclass `Side` which representing the three sides of triangle. This ` Side ` is different with `Line2D` in equality that two `Side`  are equal when P1 and P2 are equal correspondingly or, one `Side`'s P1 are equal to another `Side` 's P2 and one `Side`'s P2 are equal to another `Side` 's P1 are equal.

`getSides()` will return three sides of the triangle. `getCircumcircle()` will return the circumcircle of the triangle that would be later used in `Delaunay` class. `sharesVertex()` will check if the specified triangle shares vertex/ point.

##### Fields

Three vertices of triangle. Sorted by their x and y coordinates from smaller x to bigger x, and smaller y to bigger y if x are same.

```java
private final Point2D a; 
private final Point2D b;
private final Point2D c;
```

#### Delaunay

A class that will take a list of points and create delaunay triangles by bowyerwatson algorithm. `getSides()` will return a set of sides of all triangles.

##### Fields

`private final Set<Triangle> delaunayTriangles;`



### 3. Package Graph

#### EuclidenDigraph, EuclidenGraph: 

no usage. Written as a practice for EuclidenEdgeWeightedGraph.

#### EuclidenEdgeWeightedGraph

A Euclidean representation of an edge weighted graph, whose vertices are points on the plane and edges are lines on the plane.

It takes a `Collection<Line2D>` as contructor parameter.

 * It works as a wrapper. It uses a map to store the mapping from each point to the index,
 * and an array to store the mapping from the index to the point.

`show()` method will draw out the graph via `StdDraw`.

##### Fields

```java
private final Map<Point2D, Integer> map; // Point2D -> index
private final Point2D[] keys; // index -> Point2D
private final EdgeWeightedGraph graph; // the graph
```

#### EuclidenPrimMST

A Euclidean representation of the MST of an EuclideanEdgeWeightedGraph. 

It's constructor will take an EuclideanEdgeWeightedGraph and `sides()` methods will return a set of `Line2D`.

`show()` method will draw out the graph via `StdDraw`.

##### Fields

`private final EuclideanEdgeWeightedGraph graph;`



### 4. Package DungeonMap

#### DungeonMap

It represents the map of game.  The `Setting` and `Random` object will be set in the constructor. 

A number of  `RandomRooms` will be created.  Then the location of centers of the `mainRooms` from `RandomRooms` are used to generate the delaunay triangles. 

A Euclidean weighted undirected graph will be built on the sides/ edges of these delaunay trianges. Then we will get the MST (minimum spanning tree). 

We randomly choose 15% edges from sides/ edges of delaunay triangles and added them into edges of MST to build the main path of map. 

We call `buildHallwayPaths()` method to get the `hallwayPaths` ( vertical or horizontal pathways) from `mainPath`. Then we calculate the `hallwayWallVariation` by adding the `sideRooms` from `RandomRooms`  that cross with the `hallwayPaths`.

The call of `getWorldFrame` method will return a TETile representation of the map will can be rendered by `TERenderer` directly. 

Method `showGraph()` will render the progress of map generation If the env variable DEV_ENV is true.

##### Fields

```
/**
 * The settings of the game
 */
private final Settings settings;
/**
 * The random object
 */
private final Random random;
/**
 * The generated random rooms whose centers are inside the "center ellipse".
 */
private RandomRooms randomRooms;
/**
 * The graph data structure that support Euclidean weighted graph.
 * Stores the graph that generated by the Delaunay triangulation.
 */
private EuclideanEdgeWeightedGraph graph;
/**
 * The minimum spanning tree of the graph.
 */
private EuclideanPrimMST mst;
/**
 * The main path of the dungeon map. Contains some additional edges other than the minimum spanning tree.
 */
private List<Line2D> mainPath = new ArrayList<>();
/**
 * The paths of hallways of the dungeon map. Hallways are either vertical or horizontal.
 */
private List<Line2D> hallwayPaths = new ArrayList<>();
/**
 * The rectangles of the hallways.
 */
private List<Rectangle> hallwayWallVariation
```
